# Data Structure & Graph Performance Analyzer

**Module:** CIT300 Data Structures and Algorithms
**Assignment:** Graded Practical Assignment 2 (Week 12)
**Language:** Java (console-based)

## Project Description
A single integrated Java console application that demonstrates arrays, stacks, queues, linked lists, searching, graphs (BFS/DFS) and a performance comparison of algorithms (steps and execution time). All inputs are validated and empty/invalid operations are handled safely.

## Main System Features
1. Array operations (insert, delete, search, display)
2. Stack operations (push, pop, peek, display)
3. Queue operations (enqueue, dequeue, peek, display)
4. Linked list operations (insert, delete, search, display)
5. Searching (Linear vs Binary)
6. Graph operations (add vertex, add edge, display, BFS, DFS)
7. Performance comparison (steps and execution time)
8. Display all results
9. Input validation and empty-structure handling

## How to Run
1. Install JDK 17 or later.
2. Clone the repository:
   `git clone https://github.com/[username]/[repo-name].git`
3. Open the folder: `cd [repo-name]/src`
4. Compile: `javac *.java`
5. Run: `java Main`
